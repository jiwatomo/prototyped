# Diagram Mermaid

Satu diagram per file. Buka file `.mmd` lalu tempel isinya ke mermaid.live, atau
gunakan ekstensi Mermaid di editor. Jangan menempelkan seluruh `flow.md` ke mermaid.live —
penampil itu hanya menerima satu diagram, bukan dokumen Markdown.

Salin cepat: `./copy.sh <nomor>`.
